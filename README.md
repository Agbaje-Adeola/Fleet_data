# Fleet_data: Fuel Consumption Optimisation & Fleet Analytics
This project uses synthetic fleet data to estimate and predict vehicle fuel consumption across different transportation scenarios, ranging from light-duty vans to heavy-duty trucks. The model combines vehicle specifications, service history, load utilization, route distance, and traffic conditions to generate estimated fuel consumption before a vehicle begins a trip. To improve realism, the project is being integrated with Google Maps APIs to retrieve live traffic and route metrics for more accurate trip analysis.

# In addition to fuel estimation, the project also provides operational insights through interactive dashboards that identify monthly:
- Vehicles with the highest fuel consumption
- Department-level fuel usage
- Route efficiency trends

# This is specifically designed for logistics and supply chain managers to:

Budget Accurately: Calculate the exact liters needed for routes (e.g., Point A to B, or Point A to B to C).

Diagnostic Alerts: Track maintenance history to explain vehicle behavior. If a vehicle consumes more fuel than predicted, it could be flagged as it needing servicing or cooling system checks.

Scalability: The underlying predictive logic can be adapted to track any resource consumption rate beyond just vehicles and fuel.

# Key Features:
- Comprehensive vehicle database with real engine specifications
- Maintenance-based fuel efficiency adjustments
- Live traffic and GPS integration
- Dynamic consumption estimation based on departure timing
- Synthetic operational dataset designed to simulate real-world fleet behavior

# Data 
Since real-world fleet data is private, this project utilizes Synthetic Data. I carefully generated this dataset to mirror real world engine behaviors and fuel burn rates to ensure the logic remains technically sound and scalable.
